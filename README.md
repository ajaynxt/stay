# Aurevia Retreat & Spa Demo

Original fictional luxury hotel and resort website created for the AJAYNXT portfolio.

## Included

- Original nature-led SVG logo
- Cinematic resort hero
- Check-in, check-out, guest and room search
- Room, suite and villa filters
- Room-detail modal and booking enquiry
- Curated offers
- Dining venue selector
- Spa booking concept
- Destination experiences
- Weddings and private-events section
- Gallery lightbox
- Resort-map concept
- AJAYNXT website-price form
- Automatic colour and heading-font changes every 3 seconds
- Manual colour picker, HEX and font selector
- Colour lock, font lock and lock both
- Light, dark and system modes
- Responsive/mobile actions
- SEO, JSON-LD, sitemap, robots, manifest, favicon, 404 and CNAME

## GitHub Pages

1. Upload all files to repository root.
2. Open Settings → Pages.
3. Choose Deploy from a branch.
4. Select `main` and `/root`.
5. Save.
6. Set custom domain to `stay.ajaynxt.com`.

## DNS

- Type: CNAME
- Name: stay
- Value: ajaynxt.github.io
- TTL: default or 30 minutes
